# Product media

These WebP images are screenshots of CodinginX's working internal demonstrations, captured at desktop and mobile widths. All displayed people, companies and requests are fictional samples. These images represent neither client work nor a live AI/CRM integration.

- `intake-desktop.webp`: real rule-based inquiry extraction with editable output.
- `operations-desktop.webp`: real browser-local scheduling/status interface.
- `operations-mobile.webp`: the same operations interface at a mobile width.

To refresh, run the local website, then `node scripts/capture-product-media.mjs` in a separate terminal. Install Playwright Chromium first if the system browser is unavailable. The script verifies extraction actually completed, captures the real interface, and encodes WebP at quality 90. Next Image supplies responsive sizes and intrinsic dimensions. No invented metrics, external-provider delivery or generated founder photography is included.

Real client material must have publication approval and its own truthful project record. Supplied founder photography belongs in the central founder model, with approved alt text and dimensions.
